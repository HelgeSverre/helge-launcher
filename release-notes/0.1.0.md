## First release

- Launcher panel on ⌘Space with fuzzy search ranked by how often and how recently you open things
- Applications, CleanShot X commands, emoji, snippets and clipboard history
- 1Password items through the `op` CLI: copy password, username or one-time code
- AI answers through `opencode serve` (default model `opencode-go/deepseek-v4.1-flash`)
- Config in `~/.config/hl/config.toml`, reloaded on save; external plugins over JSON
- Accessibility helper that pins a draggable app icon to System Settings
