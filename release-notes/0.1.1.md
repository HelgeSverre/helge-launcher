## Fixes

- AI: the `opencode serve` process stops with the launcher instead of being left running, restarts if it dies, and picks up config changes
- AI: a new question while an answer is streaming, or ⌘N during a slow start, no longer mixes two answers in one chat
- Plugins: pressing Esc while a slow plugin is still answering no longer drops its results into the main list
- The ⌘K menu, Pin and a click with the menu open act on the item you selected, not on whatever moved into its row
- Plugins that write a lot to stderr no longer time out; cancelled queries stop
- 1Password secrets from `op://` snippets are kept out of clipboard history, cleared after `clear_after` seconds, and never pasted into an app you switched to while 1Password was asking for approval
- Fixing a broken or missing `include` file reloads the config; a save during a reload is no longer missed
- A new install no longer shows a config error for the missing `snippets.toml`
- Clipboard history stores each image once, deletes image files with their entry, and keeps a damaged history file aside instead of deleting your images
- Plugins now gain frecency like apps
- "Grant Accessibility…" disappears from the menu once access is granted
- `helgelauncher://show?q=` opens the main list even after an AI chat; `ai?q=` keeps the question when an answer is still streaming
