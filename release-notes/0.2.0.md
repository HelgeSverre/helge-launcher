## New

- Calculator: type a sum, a unit or currency conversion, a date or a time-zone question straight into the search: `1.5 l per day for a year at 2 kr/ml in usd`, `12am texas in norway`. Exact arithmetic, live exchange rates (Norges Bank, CoinGecko), ⌘I shows each step of a chain ([calculator.md](https://github.com/HelgeSverre/helge-launcher/blob/main/docs/calculator.md))
- AI chat: full GitHub Markdown (tables, task lists, alerts, `<details>` sections), syntax-highlighted code with Copy, live activity (searching, reading pages) instead of "Thinking…"
- AI chat: saved conversations (⌘Y) to search and continue; ⌥↑/⌥↓ steps through answers and ⌘. opens a menu per answer (copy as Markdown or plain text, copy or paste code, quote, ask again)
- AI chat: copy the whole chat as Markdown (⌥⌘C) or save it to Downloads (⌘S)
- Usage Statistics: launches in total, today and this week, the split by kind, and every app and command ranked by use; also at `helgelauncher://stats`
- Emoji search covers every emoji macOS has (1 900+, including skin-tone and family sequences and all flags) with Apple's names

## Changes

- Numbers always show as `1 000 000.00`, whatever the system region
- Shortcuts show one key cap per key in the system font, so `⇧⌘C` is readable
- Commands run by their own global hotkey now count towards ranking
- `just uninstall` and `just reinstall`
